# Benchmarks

Reserved for the performance and reconstruction-quality benchmark suite
(roadmap Milestone 9).

Planned coverage:

- Cartesian vs. non-Cartesian
- parallel imaging and iterative reconstruction
- CPU vs. GPU backends
- varying matrix size, coil count, acceleration factor

Planned measurements: runtime, peak memory / VRAM, reconstruction quality
(NRMSE / PSNR / SSIM against a reference), numerical accuracy vs. BART / sigpy,
and scaling behaviour.

Nothing here runs yet.
